# SRE Agent Domains

This workspace tracks a small set of vendor domains related to simulation, AI for production systems, and incident management.

## Domains

### Simio
Website: https://www.simio.com/

Simio focuses on digital twin simulation and discrete event modeling.
It is used to test what-if scenarios, improve operational planning, and optimize complex systems before making real-world changes.

### Resolve AI
Website: https://resolve.ai/

Resolve AI is built for AI-powered production support.
It helps teams investigate incidents, understand production context across code and infrastructure, and speed up remediation.

### Rootly
Website: https://rootly.com/

Rootly provides AI-assisted incident management and on-call workflows.
It helps teams respond to incidents faster, automate post-incident work, and keep stakeholders informed.
